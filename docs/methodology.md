# 数据、模型与评估机制

## 一条样本如何形成

原始 LIBERO Spatial 10任务×50示教，共500条。原始 `observation[t]` 对应执行 `action[t]` 后的观察，因此转换时将 `observation[t]` 配到 `action[t+1]`，每条轨迹舍弃最后一个没有后继动作的观察。总有效监督帧为61,750。转换后同行已对齐，训练读取时不再错开一帧。

先从原始 HDF5 保留全部500条进行转换，再生成独立的 `libero-spatial-train500-v1`：全部 episode 归入训练，重新计算统计；不复用旧450条统计。图像在转换中完成128渲染原图旋转180°、双线性256与压缩存储，模型变换最终到224。官方评估则256渲染后旋转并按固定PIL路径到224；两条路径需分别说明。

每个样本包含双相机图像、语言指令、记录的8维state、未来10步7维动作。动作本身已是增量控制，不再次差分；轨迹尾部不足10步时重复最后动作，不跨 episode。OpenPI 侧将动作补至32维。π0.5 本项目配置 `discrete_state_input=false`，没有连续state token；不能因为接口中存在state就宣称该配置使用了数值本体状态条件。

归一化采用训练数据 q01/q99，近似映射到[-1,1]但不裁剪离群值；部署反归一化使用对应训练统计。Base也使用本轮500条训练统计。

## 模型和目标

沿用 OpenPI π0.5 的视觉语言前缀与动作专家，不从头预训练。语言模型Attention/FFN LoRA rank16、alpha16，动作专家LoRA rank32、alpha32。A只配置动作专家LoRA，B/C配置双LoRA，D仅配置语言LoRA并更新动作专家原权重。

本项目展开的前向位于 `model.py`：时间 t 来自缩放后的 Beta(1.5,1)，噪声 ε 与动作块同形状，构造 `x_t = t ε + (1-t) a`，目标速度为 `ε-a`；预测速度与目标做均方误差。t=1一侧是噪声，推理从噪声向数据侧积分；本轮denoise_steps=10。动作块长度10与去噪迭代10是两个不同维度。

可训练参数为FP32，冻结参数为BF16，前向计算BF16；所以改变范围也改变部分参数存储精度。只能称适配策略对比，不能称完全隔离精度因素的模块因果消融。

## 更新与恢复

global batch32；逻辑microbatch2×16，4卡并行时每卡累计4个microbatch。每组3000次优化器更新，warmup100、峰值5e-5、末值5e-6，余弦衰减；每500步保存最终状态。额外第2步checkpoint用于恢复连通性，接续2998步。

checkpoint包含模型/优化器状态、更新计数、RNG与采样游标及配置；恢复不等于只载入权重。展示脚本验证A–D每一步的sample_indices完全一致；并未重新执行模型来生成曲线。第1步与恢复后第3步日志标记为包含编译，耗时统计排除这两点。

## 闭环过程

载入官方 `.pruned_init` → 恢复环境 → 稳定10步 → 双相机观察与任务语言 → 模型预测10步 → 反归一化 → 执行前5步 → 获取新观察。最多220个控制步，环境成功条件触发即结束。所有方法共享500条manifest，动作噪声按(seed,task_id,initial_state_id)配对。

这不是播放示教动作，也不是评估训练loss。每组500条独立编号记录、50条/任务；本轮包含训练过的任务，不声称未见任务泛化。step3000预先固定，不根据本轮闭环分数挑checkpoint。

## 代码阅读顺序

1. `convert_spatial_500.py` 的对齐与统计；`dataset.py` 的 `get_frame/get_action_chunk`。
2. `model.py` 的 `lora_config/get_trainable_filter` 和前向展开。
3. `train.py` 的 `TrainState`、梯度累积和多卡路径。
4. `checkpoints.py` 的保存恢复字段。
5. `evaluate.py` 的官方清单生成、`policy.infer`与`env.step`循环。

源码快照与配置是事实依据；正文省略了一些环境细节，复现时以固定依赖和配置为准。
